Comparison of sandbox/analysis services usable for automated honeypot payload submission.

## VirusTotal API v3

- **Endpoint**: `https://www.virustotal.com/api/v3/files`
- **Auth**: `x-apikey` header
- **Upload**: POST multipart/form-data, files ≤ 32 MB direct; use `/files/upload_url` for up to 650 MB
- **Flow**: Upload → get `analysis_id` → poll `GET /analyses/{id}` until `status == completed` → fetch `GET /files/{sha256}`
- **Free tier**: 4 requests/min, 500 requests/day, 15 500/month
- **Premium**: no public cap; governed by SLA
- **Report formats**: JSON only (PDF generated by our pipeline via weasyprint)
- **Behaviour data**: `/files/{sha256}/behaviour_summary` (premium)
- **Deduplication**: automatically skips re-analysis if hash is already known
- **Python SDK**: `pip install vt-py` (official)

### Key endpoints used
| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/files` | POST | Upload file (< 32 MB) |
| `/files/upload_url` | GET | Get pre-signed URL for large files |
| `/analyses/{id}` | GET | Poll analysis status |
| `/files/{sha256}` | GET | Fetch full report |
| `/files/{sha256}/behaviour_summary` | GET | Dynamic analysis summary (premium) |

## JoeSandbox Cloud API v2

- **Endpoint**: `https://jbxcloud.joesecurity.org/api/v2`
- **Auth**: `apikey` POST parameter
- **Upload**: POST multipart/form-data to `/analysis/submit`
- **Flow**: Submit → get `webid` → poll `/analysis/info` until `status == finished` → download PDF via `/analysis/download?type=pdf`
- **Free community tier**: limited monthly submissions (exact quota varies)
- **Systems**: `ubuntu22x64`, `windows10`, `android`, etc.
- **Report formats**: PDF, JSON, XML, HTML, MISP, STIX
- **Report cache**: `report-cache: 1` reuses existing analysis for known hashes (avoids wasting quota)
- **Python**: manual `requests` calls (no official SDK)

### Key endpoints used
| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/analysis/submit` | POST | Submit sample |
| `/analysis/info` | POST | Poll status (param: `webid`) |
| `/analysis/download` | POST | Download report (param: `type=pdf`) |

## Design Decisions

1. **VT first**: Check hash before uploading to avoid wasting quota on known samples
2. **Rate limiter**: 16s sleep between VT requests keeps comfortably under 4 req/min
3. **Joe cache**: `report-cache: 1` skips re-analysis of known hashes
4. **PDF generation**: VT returns JSON only — weasyprint renders a styled HTML template to PDF
5. **Joe PDF**: downloaded directly from Joe's `/analysis/download?type=pdf` endpoint
6. **IOC CSV**: updated after every sample with hashes, VT detections, and Joe webid reference
