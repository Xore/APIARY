# write/mutate operation, not just a fetch -- either because the operation a
# sample legitimately needs there is inherently bidirectional, or because
# the domain itself accepts anonymous writes. Kept separate from
# forensic-egress-allowed-domains-read.txt so an operator narrowing this
# allowlist knows which entries to cut first.

# push -- there is no GET-only subset of "talking git to github.com".
.github.com
