Plants a username/password pair into Cowrie's live honeyfs via the honeyfs-implant service (#1553). Rotating re-implants the same path with a new password — the file's location never changes.

Credential history is unavailable on this host (Elasticsearch not configured) — provisioning also requires HONEYFS_IMPLANT_URL to be set; a submit attempt below will report either as an error if unconfigured.
