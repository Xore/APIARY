# APIARY web starter

`index.html` is a dependency-free implementation specimen. `apiary-theme.css`
contains the portable tokens and components; copy it before adapting markup to a
framework.

The template includes:

- responsive navigation, hero, cards, evidence panel, buttons, status pills, and footer;
- dark and light tokens aligned with the production dashboard;
- accessible focus states and reduced-motion behavior;
- canonical favicons, manifest, themed logos, and hero artwork.

Do not hotlink these paths from another project. Copy the required files from
`branding/assets/` and preserve the relative structure or update the URLs.
